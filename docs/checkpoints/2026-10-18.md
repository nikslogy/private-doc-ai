## Changes in this checkpoint

- Import now stores native PDF/UTF-8 text, page identity/geometry, source spans,
  extraction version and indexing state inside SQLCipher.
- Room schema 1→2 migration preserves original revision IDs/digests/objects;
  older documents are marked not indexed and can be explicitly indexed.
- Encrypted FTS4 content search uses bounded literal queries and source-checked
  UTF-16 page quotes. Devanagari combining marks, identifier zeroes and number
  separators are retained. No semantic/current-policy/financial-answer claim.
- Documents UI includes content hits, indexing badges, a page-text evidence
  viewer and explicit native-text extraction. Session/generation checks prevent
  stale search/evidence publication after lock or selection changes.
- Images get PNG framing/CRC and JPEG scan framing checks, bounded sampled pixel
  decoding and all eight EXIF orientation transforms without plaintext files.
- ML Kit is **test-only** because its documented diagnostics conflict with the
  no-telemetry rule. Production OCR remains unavailable in both flavours. The
  real development adapter waits for its Task before recycling the bitmap and
  checks INTERNET is denied before SDK initialization. This is not a supported
  diagnostics opt-out or a production privacy qualification.
- APK verification now inventories native ABIs/hashes and checks 64-bit ELF
  PT_LOAD plus uncompressed ZIP payload alignment for 16 KiB compatibility.
  The production runtime dependency task rejects accidental ML Kit inclusion.
- A repository-owned deterministic source packager includes checksums and an
  optional record of checks actually executed.

## Data and failure invariants

Original objects are never rewritten by extraction/search. Evidence/FTS/spans
and state publish in one session-checked transaction; deletion removes them
transactionally before original ciphertext unlink. Failed extraction preserves
previous valid evidence. Cancellation restores previous evidence/status; lock
prevents an old session from publishing. Interrupted `INDEXING` becomes
`FAILED` on unlock for explicit retry, never an automatic background OCR job.

Blank/raster pages report needs OCR; valid native pages remain searchable.
Search uses at most 200 FTS candidates and returns at most 50 source quotes.
Query limit is 512 UTF-16 units/24 terms. Exact literal matching does not infer
identity, policy coverage, currency, field meaning or a correct answer.

FTS hex tokens are reversible private content, not an encryption primitive;
SQLCipher protects their tables/shadow tables/journals. All claimed at-rest
boundaries still require device leakage tests. PDF/native/provider timeouts and
cancellation are cooperative, not hard process isolation. Image framing and
sampled decode are bounded validation, not a promise for all malformed files.

Export writes ordinary external plaintext and may leave a partial file if the
destination refuses cleanup; the UI reports that refusal. Its picker still
uses the 15-second background timeout. Recovery/rotation/backup remain absent.

The source corpus still has six documents/seven illustrative labelled cases,
not the 120-case release suite. SDK platform-tools remains an official rolling
package. The original temporary plan attachment vanished on environment
restart; DEVELOPMENT_PLAN.md is a marked condensed transcription. None of
these limits has been silently treated as release completion.
